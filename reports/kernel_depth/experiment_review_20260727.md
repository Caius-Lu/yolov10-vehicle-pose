# Vehicle Pose 压缩/剪枝实验复盘（2026-07-27）

## 目标与当前状态

- 约束：只做 PyTorch 模型压缩/剪枝，不使用 TensorRT。
- 精度准入线：Box mAP50-95 ≥ 0.64761，Pose mAP50-95 ≥ 0.49455。
- 延迟准入线：相对原始完整 baseline 的 paired fused-FP16、batch=1、
  640、one-to-one-only 延迟至少下降 10%。
- 原始 baseline 完整验证约为 Box/Pose 0.665/0.515；最终 fused-FP16
  验证为 0.665/0.514。
- 当前最优结构为 P5-Zero：5.94537→5.06345 ms，加速 **14.83371%**；
  fused 参数 3,992,210→3,387,794（-15.13989%）。
- 当前最佳精度为 Box/Pose **0.66254/0.49592**，完整 fused-FP16 复验为
  0.662/0.496；首次形成速度、精度、CUDA 内存同时通过的结构候选。
- ClassLite52 分类+姿态头无 KD 监督精修已完成 12 轮；最后一轮为
  0.62505/0.46712，仍略低于总最佳 0.62507/0.46795，确认该结构在当前
  监督方式下进入平台。

## 关键发现

1. **参数量不是本项目 GPU 延迟的可靠代理。** 多组结构化通道剪枝虽然减少
   15%–52% 参数，却没有变快；真正有效的是减少串行 kernel/卷积层。
2. **速度与精度的矛盾主要集中在分类塔。** 完整 box/pose tower 保留后，
   ClassLite 仍会同时影响 Box 和 Pose mAP，因为分类置信度参与最终匹配与评分。
3. **简单 tensor slicing 是错误的迁移策略。** 它保持 shape，却破坏通道语义；
   投影折叠、定向 pointwise 搬运、padding 热启动明显更可靠。
4. **选择性训练必须固定冻结 BN 的统计量。** 参数 `requires_grad=False`
   仍不足以冻结行为；早期 Pose 0.484→0.418 的退化正是 BN running stats 漂移。
5. **KD 不是自动增益。** 当前分类瓶颈下，无 KD 真实标签监督达到
   0.62507/0.46795，明显好于多组输出/特征 KD；异构教师还会引入上游特征分布
   不一致。
6. **部署分支裁剪是最稳的压缩成果。** 它不提升明显延迟，但在输出逐元素一致
   的前提下减少约 27% 参数/文件、约 9% 推理峰值显存，应与结构延迟优化分开交付。
7. **延迟余量需要更大。** ClassLite52 只超过门槛 0.54 个百分点；
   不同测量时钟下仍需最终重复 paired benchmark，不能提前宣称稳定通过。
8. **低分辨率 P5 是更好的串行深度压缩点。** 只删除两个 P5 内部
   bottleneck，保留 P3/P4 与完整任务塔，可同时获得 14.83% 延迟收益和
   门槛以上的 Box/Pose 精度；继续删除 P4 则出现不可恢复的姿态退化。

## 过程问题与改进

- WSL 多次卡在 `p9_client_rpc`，通常约 2–3 分钟自行恢复。后续应复用已生成的
  dataset cache、减少不必要的重复 trainer 初始化，并给数据扫描单独计时。
- 早期一次批量 scp 把 7 个文件放到远端根目录，另一次创建了错误的
  `ultralytics/models/yolov10/head.py`；均在精确核对后只删除新建误文件。
  后续同步必须逐文件指定完整目标路径。
- 部分实验在速度 gate 失败后立即停止是正确的；但 ClassLite48/52 上连续尝试
  多种 KD 的信息增益较低。更好的顺序应是：热启动完整验证 → 纯监督头部消融
  → 仅在监督明显平台后做一个低权重 KD 对照。
- 每轮应统一保存一个机器可读汇总，包含 paired latency、参数、训练峰值显存、
  Box/Pose/PCK/NME 和停止原因，减少从多个 CSV/JSON 回溯的成本。

## 当前结论

- **已达成：** 不损精度的部署体积/显存压缩；baseline 的 fuse+FP16 延迟优化。
- **已达成：** P5-Zero 同时满足相对原始 baseline 延迟快 ≥10%、
  Box/Pose ≥0.64761/0.49455 和 CUDA 内存下降。
- **最终候选：** P5-Zero，延迟 -14.83371%，Box/Pose
  0.66254/0.49592，模型驻留/推理峰值显存 -6.28626%/-5.02307%。
- ClassLite52 头部无 KD 监督已完成并确认平台，不应继续在该结构上重复微调。
  后续将其保留为失败对照；已按该复盘转向保留完整分类塔，并在 backbone/
  neck P5 找到可做投影折叠、确定减少串行 kernel 的 P5-Zero。
